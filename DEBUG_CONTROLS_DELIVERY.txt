                       FEATURES IMPLEMENTED
================================================================================

DEBUG CONTROL BUTTONS (7 TOTAL):

1. Continue/Run (F5) - Green button
   GDB Command: c
   Enabled when: Target paused

2. Pause/Break (F6) - Yellow button
   GDB Command: Ctrl+C
   Enabled when: Target running

3. Step Over (F10) - Gray button
   GDB Command: n
   Enabled when: Target paused

4. Step Into (F11) - Gray button
   GDB Command: s
   Enabled when: Target paused

5. Step Out (Shift+F11) - Gray button
   GDB Command: finish
   Enabled when: Target paused

6. Restart (Ctrl+Shift+F5) - Gray button
   GDB Command: run
   Enabled when: Always (if attached)

7. Reset (no shortcut) - Yellow button
   GDB Command: monitor reset
   Enabled when: Always (if attached)

KEYBOARD SHORTCUTS (6):
- F5: Continue/Run
- F6: Pause/Break
- F10: Step Over
- F11: Step Into
- Shift+F11: Step Out
- Ctrl+Shift+F5: Restart

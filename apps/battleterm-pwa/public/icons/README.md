# Icons Directory

Place PWA icon files here:

- `icon-192x192.png` - 192x192 pixel icon
- `icon-512x512.png` - 512x512 pixel icon

These icons should feature the BattleTerm branding with:
- Theme color: `#10b981` (emerald green)
- Background: `#000000` (black)
- Terminal/console themed design

Icons are referenced in:
- `public/manifest.json` - PWA manifest
- `src/app/layout.tsx` - Apple touch icon

## Icon Requirements

For best PWA experience:
- PNG format
- Transparent or black background
- Purpose: "any maskable" (works for both regular and masked icons)
- Consistent branding across sizes
